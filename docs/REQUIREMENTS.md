# Согласованная модель

## Назначение
Минимум действий сотрудников, прозрачность всех ПИД для наблюдателей, один первичный ввод.
Единый Mini App: формы → проверка → подтверждение. Чат — запросы и сводки.

## Роли
- Администратор: роли, закрепления, ПИД, справочник, замеры, начальные данные, корректировки, выгрузка.
- Прораб: своя бригада; несколько ПИД; отдельный отчёт по каждому ПИД и дате.
- Намотчик: длина намотанного кабеля в метрах и количество готовых катушек по типам; позднее уточнение длины и веса в той же записи.
- Отправитель: один рейс одного ПИД, массы группами по типам.
- Кладовщик: единственный постоянный склад, все ПИД, каждая катушка отдельно в свободном порядке.
- Наблюдатель/собственник: все ПИД, объёмы, остатки, поставки, первичные записи, авторы, пропуски, история, расхождения.
В одном профиле допускается несколько назначенных ролей; права проверяет сервер.

## Ввод
Прораб вводит траншею и извлечённые метры. Один тип в день на бригаду/ПИД.
Количество ниток не запрашивается; отношение метров может быть любым, в том числе нулевая траншея при ненулевом извлечении.
Прораб выбирает тип из справочника; новые типы создаёт администратор.
Кабель извлечён на трассе. Поле и временная площадка относятся к одному ПИД; отдельное перемещение между ними не фиксируется. Отправка на постоянный склад — отдельный рейс.
Метры — основная единица первичных измерений и производительности намотки. Катушки в штуках дополняют метры, но не заменяют их. Измеренный метраж намотки — часть уже извлечённого кабеля, а не новое поступление.
Количество катушек, измеренная длина и масса могут стать известны в разное время. Намотку можно подтвердить без взвешивания; неизвестная длина сохраняется как null и отображается как «уточняется», а не как ноль.
Позднее в той же записи добавляют измеренную длину и/или массу всей указанной партии катушек без тары, дату взвешивания. Контрольный замер по ПИД/типу и дате взвешивания даёт отдельную расчётную длину. Измеренная длина и расчётная по весу сохраняются одновременно; расчёт не подменяет измерение и не меняет запас автоматически.
Отправка — список масс в кг без тары для каждого типа; в каждой катушке один тип; рейс одного ПИД.
Приёмка — фактический вес каждой катушки, произвольный порядок. Все катушки должны быть взвешены; частичные приёмки в первой версии не поддерживаются.
Дата ответа на запрос относится к дате запроса. Можно выбрать прошлую дату.
Выходной и простой не заполняют числовые поля. Пояснение к простою необязательно: текст или голос.

## Расписание
Asia/Krasnoyarsk: 19:00 отдельный запрос каждому ответственному прорабу/намотчику по активным закреплениям.
20:00 одно напоминание, если отчёт не подтверждён.
21:00 общая суточная сводка в группе, с несданными отчётами.
Отправки ежедневными запросами не охватываются.
Отдельных групповых уведомлений об отправках, приёмках и исправлениях нет.

## Остатки
ПИД + тип кабеля. Начальные остатки и накопленные работы разделены.
Форма начала учёта разделяет «Кабель на ПИД — ещё не отправлен на склад» и «Работы, выполненные до начала учёта».
Первый блок: весь извлечённый кабель в поле и на временной площадке в метрах; из него — катушки и длина кабеля в этих катушках, при наличии вес. Кабель в пути и на постоянном складе сюда не включается.
Второй блок: всего ранее извлечено в метрах, всего ранее намотано в метрах и катушках независимо от текущего места кабеля, включая уже отправленный. Эти объёмы не прибавляются к начальному остатку и не задают остаток склада.
Метры расчётные: начало + извлечение − эквивалент отправки + корректировки.
Катушки: начало + намотано − отправлено + корректировки.
Намотка не меняет общий метраж. Приёмка не уменьшает остаток ПИД второй раз.
Коэффициент из контрольного отрезка отдельно для ПИД/типа. Новый замер применяется к новым отправкам; коэффициент каждой уже созданной катушки отправки фиксируется.
Минус допустим. Сам по себе не является недостачей или денежным убытком.
Администратор корректирует по проверенному фактическому остатку с основанием. Автоматического доведения до нуля нет.
Полностью принятый рейс выходит из «В пути» весь, даже при расхождении массы.
На постоянном складе показывается «Принято накопленно», а не текущий запас; последующее выбытие не входит в первую версию.
Номера катушек временные, в пределах ведомости рейса; после сверки остаются в архивной первичной ведомости.

## Исправления
Автор вправе менять подтверждённый отчёт без временного ограничения. Сохраняются авторство, редактор, время, версии.
Поздние записи пересчитывают итоги и помечают затронутые корректировки для повторной проверки.
Нет повторного суммирования версий и повторных нажатий.
Неизвестный тип/ПИД, чужая роль, дробные штуки, нулевые/отрицательные массы, неполная приёмка — ошибки ввода.
Отрицательные остатки и разница весов — допускаемые результаты учёта.

## Выгрузка
1С:УНФ; пока свой XLSX. Только администратор, по выбранному периоду.
Отправки, приёмки, изменения, описание формата. Массы — кг.
Исправления ранее выгруженных строк включаются вне выбранного периода.
ID + версия + UPSERT/DELETE предотвращают дубли при корректно реализованном импортёре.
«Выгружено» не равно «Загружено». Факт импорта отмечается отдельно.
Не создавать два независимых прихода одного кабеля. Вид документов 1С и учёт площадок в 1С согласуются при разработке импортёра.

## За рамками
Линии внутри ПИД, перенос от трассы до намотки, частичная приёмка, возвраты, перемотка, списания, продажи со склада, денежная оценка потерь.
